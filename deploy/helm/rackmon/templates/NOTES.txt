RackMon is deploying.

1. Wait for pods:  kubectl get pods -l app.kubernetes.io/instance={{ .Release.Name }}
{{- if .Values.ingress.enabled }}
2. Open:  https://{{ .Values.ingress.host }}
{{- else }}
2. Port-forward:  kubectl port-forward svc/{{ include "rackmon.fullname" . }}-api 8080:80
{{- end }}
3. Sign in with secrets.adminEmail / secrets.adminPassword, the values you set
   at install time. There is no default account: the chart deploys with
   RACKMON_ENVIRONMENT=production, and RackMon refuses to start on a factory
   or "change-me" secret rather than run exposed.

If you enabled TimescaleDB features, apply deploy/timescale/20-hypertable.sql once.
